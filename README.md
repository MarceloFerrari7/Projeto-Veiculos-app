# Projeto de Análise de Veículos (Streamlit & Render)

Este projeto se aplica em um aplicativo web desenvolvido com Streamlit para explorar dados de anúncios de venda de carros (`vehicles_us.csv`).

## Funcionalidades
- **Histograma interativo**: Permite visualizar a distribuição dos dados (como o odómetro dos veículos).
- **Gráfico de dispersão**: Permite analisar a relação entre diferentes variáveis.
